              About these statistics

              Page views count page loads reported by the browser, including repeat visits and reloads. Visits count page loads that came from another site or a direct link, so one visit can contain several page views. Neither number identifies people: there is no visitor deduplication, and neither is a unique-reader count.

              Only aggregate counts are published—no IP addresses, visitor identities, full referrer URLs, or individual browsing histories. Referring sites use visit counts; other distributions use page views. “Direct / unknown” can include links from apps or browsers that omit the referrer. Country is inferred from the network location and can reflect a VPN exit.

              Source: Cloudflare Web Analytics. Updated every six hours. Cloudflare may sample or round values, so read these as approximate and comparable over time rather than exact. Dates use UTC and today is incomplete.

              Tracking started on . Earlier traffic is not included, and older dates may lack visits or audience breakdowns. Missing data is shown as unavailable, not zero. Excluding this browser affects Web Analytics only; Cloudflare can still see network requests. Repeat this setting in other browsers or after clearing site storage. Reload other open blog tabs after enabling it.
